This records the approved release with every row flagged `suspect`. The [21 November annual check](ign-coruna-clock-check-2026-11-21.md) does not establish the historical clock convention. The store flags only the offset spans in [the weekly clock fits](ign-coruna-windows-2026-11-28.md).

This is not a release of the rest of IGN’s network, raw instruments or current-year data. The public source refuses other station IDs and admits only the 24 exact hourly JM filenames in this interval. Source-level withholding also keeps excluded stations out of lists, bounds and publication. No live polling or monthly refetch is enabled. Excluded coverage and agency questions remain in [issue #181](https://github.com/openwatersio/stillwell/issues/181).

## Actual local output

The admitted input grids contain 210,384 hourly slots. The first review identified 840 numeric −9999 aggregates that must not be stored as plausible heights. The source-specific hourly/full-resolution comparison covers every one: 798 hours have wholly missing integro data, nine have partial missing data, and 33 overlap a held run with boundary values. Ordinary hourly values span −7046 to −1528 mm. [Per-year evidence](ign-coruna-2026-11-18/negative-missing-evidence.json) and [seven full-resolution input receipts](ign-coruna-2026-11-18/negative-evidence-inputs.csv) support refusing these aggregates; no replacement heights are invented. Other gauges’ genuine levels near −9.999 m remain unaffected.

A fresh local ingest after the fix wrote and read **209,544 numeric observations in all 24 years**, 1 January 2000 00:00 through 31 December 2023 23:00, leaving the 840 unusable aggregate hours as gaps. An independent row parser checked every timestamp and level, allowing float32 rounding. Every stored row retains quality flag 3 and reviewed source flag 0. The adapter requires each own-year source grid to contain every on-the-hour timestamp, including missing markers; truncated, shifted or missing-hour replies refuse even when only a day was requested. No predecessor file is fetched.

[Per-year readback](ign-coruna-2026-11-18/readback.json), real requalification and a second full readback confirm that the clock flag survives. Rebuilt bounds and [publication readback](ign-coruna-2026-11-18/publication.json) show one inactive, non-live hourly station, JM/NMMA 4.998 m, correct dates, the full derived-product/date credit and no unknown-station errata. A backfill revision can still invalidate a previously stored valid number with bad flags; a fresh gap never writes −9.999 or NaN.

[Mixed-catalog readback](ign-coruna-2026-11-18/group-readback.json) uses six current public Coruña station records for bounds plus source-owned GESLA/CMEMS/UHSLC identity lists ([receipts](ign-coruna-2026-11-18/group-input-files.json)).
