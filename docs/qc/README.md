# Quality control notes

This folder holds the store's quality control as it is, how it compares with published practice, and the sources that comparison rests on. [current-pipeline.md](current-pipeline.md) and [evaluation.md](evaluation.md) describe `main` at commit 4caa051e, and their `file:line` references are pinned to that commit, linked to it on GitHub. At that commit the store code was in `src/lake/` and its tests in `test/lake.test.ts`; they are now `src/store/` and `test/store.test.ts`. Read the references against the commit (`git show 4caa051e:<path>`).

- [current-pipeline.md](current-pipeline.md) maps every place a stored value's `flag` or `source_flag` is set or changed, with file and line references: the flag scheme, each per-value test, the per-station tidal verdict, each adapter's flag mapping, errata, cross-station checks, and when each run QCs and rewrites what.
- [evaluation.md](evaluation.md) checks that map against the code, the public store and the sources below, test by test, and ranks what to change: defects to fix now, design changes, and open questions.
- [scripts/](scripts/) holds the scripts behind the evaluation's measurements.
- [sources/](sources/) holds one note per primary source, with its citation, license, what it prescribes and page or section references. PDFs of 10 MB or less whose license allows copies are in [sources/pdf/](sources/pdf/).
