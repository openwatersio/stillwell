# IGN Tide Gauges Implementation Plan

Original candidate plan, superseded for public release by [the bounded Coruña plan](2026-11-18-ign-coruna.md).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Read IGN's reviewed and daily tide-gauge records with documented references and links to existing copies.

**Architecture:** One adapter in `src/sources/ign/`, registered through the shared source registry. Read directory inventories and select supported sensors explicitly; merge only observations sharing an established datum, with reviewed values preferred at shared timestamps.

**Tech Stack:** Node 24+, TypeScript, existing HTTP/cache helpers, node:test, recorded fixtures.

**Spec:** `docs/superpowers/specs/2026-11-14-ign-design.md`

## Global Constraints

- Node 24 or later. No new dependencies.
- Use IGN’s confirmed CC BY 4.0 terms, including commercial use and redistribution.
- Publish NMMA offsets only where the station sheet establishes that reference.
- Raw readings may join reviewed data only with an evidenced sensor-to-JM conversion.
- No public ingest or agency email is part of implementation.

## Review Focus

- A voltage channel or undocumented sensor must never become a water-level reading; pin unit and sensor selection in Task 1.
- Different BM/JM references must not share a series without a documented conversion; pin datum isolation in Task 1.
- A directory outage or truncated response must fail rather than erase stored coverage; pin failure behavior in Task 1.
- A coarser reviewed record must not discard finer reviewed timestamps on the same reference; pin precedence in Task 1.
- A neighboring gauge must not join a GESLA group on name alone; pin explicit counterpart decisions in Task 2.

## Self-review

The two tasks cover the approved adapter, source integration, tests, links, canary, documentation and planning entry. The main evidence dependency is the raw sensor's reference: the station sheets must establish a conversion or the adapter must keep raw and reviewed references distinct. No task sends an email or publishes measurements. IGN’s 17 November 2026 reply confirms that CC BY 4.0 applies to the series.

## Reference policy

Raw sensors remain separate from reviewed series because current station sheets do not establish their historical reference relationships. Reviewed files validate the named mark. MURC1 uses the published NAP-943 height; differently named historical Tenerife BMs have separate series without invented offsets. Numeric -9999 is retained as suspect because the source uses it for both real heights and missing placeholders. The original candidate design proposed a three-year refetch across all references; the bounded public release disables it so new reviewed files arrive.
