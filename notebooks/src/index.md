# Stillwell notebooks

Worked examples of reading the [Stillwell](https://github.com/openwatersio/stillwell) store. Each page queries the store from your browser with DuckDB when it loads, so what you see is current.

- [Marine Institute tide gauges](./marine-institute): pick an Irish gauge and a date range and chart its levels in OD Malin or LAT.

Each page is a Markdown file in [`notebooks/src`](https://github.com/openwatersio/stillwell/tree/main/notebooks/src). Code blocks marked `sql` or `js` run in the page.
