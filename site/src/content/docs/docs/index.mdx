import { rows, json } from "../../../lib/store";

export const sources = await json("sources.json");
export const counts = new Map(
  (
    await rows(`
      SELECT source, count(*)::INT AS stations, count(*) FILTER (WHERE status = 'active')::INT AS active,
        count(*) FILTER (WHERE live)::INT AS live, count(*) FILTER (WHERE commercial_use)::INT AS commercial, min(first) AS first
      FROM 'https://stillwell.openwaters.io/stations.parquet' GROUP BY source`)
  ).map((r) => [r.source, r]),
);
export const totals = [...counts.values()].reduce(
  (t, r) => ({
    stations: t.stations + r.stations,
    active: t.active + r.active,
    live: t.live + r.live,
  }),
  { stations: 0, active: 0, live: 0 },
);
export const n = (x) => x.toLocaleString("en-US");

Stillwell is an open store of observed and predicted water levels from tide, river and lake gauges around the world. It fetches each agency's data from the agency itself, checks its quality, and publishes it in one layout: times in UTC, levels in meters with the offsets to other datums, one scale of quality flags, and each station's terms. [Open Waters](https://openwaters.io) builds it to reduce crowdsourced soundings to chart datum and to show in [Slackwater](https://slackwater.xyz) how far the water is from the prediction. It's open for anyone else who needs gauge data without writing an adapter for each agency.

As of the site's last build, the store holds {n(totals.stations)} stations from {sources.length} sources, {n(totals.active)} of them active and {n(totals.live)} polled every hour.

Everything is [Parquet](https://parquet.apache.org/) at `https://stillwell.openwaters.io/`, readable over HTTPS without an account by DuckDB, Polars, pandas, R or anything else that reads Parquet. [Getting started](/docs/getting-started/) reads it in a few lines.

Commercial use counts stations, since a contributor's own terms can apply to some of a source's records, as at GESLA; each station carries its own terms. [Issues labeled `source`](https://github.com/openwatersio/stillwell/issues?q=is%3Aissue%20state%3Aopen%20label%3Asource) track the sources still to come.

## Terms and credit

The data is [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) © [Open Waters](https://openwaters.io), with two conditions from the sources:

- Stations whose `commercial_use` is false keep their source's or contributor's terms.
- Show each station's `attribution` wherever its data is used, and its `datums_attribution` wherever you use its datum offsets. Both are in `stations.parquet`; [Stations](/docs/reference/stations/#terms) describes them.

The code that builds the store is [AGPL-3.0](https://github.com/openwatersio/stillwell/blob/main/LICENSE), at [openwatersio/stillwell](https://github.com/openwatersio/stillwell).

The data is not for navigation. Observations are mostly preliminary, and a gauge can fail without warning.

## When the store changes

| What                                                     | When                                                                                         |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `recent/<source>.parquet`, the last 7 days               | Every hour, for stations polled live                                                         |
| Year files under `obs/`, `extremes/` and the predictions | Each day folds into its year file at 00:45 UTC                                               |
| `stations.parquet`                                       | Rebuilt after that nightly compaction, so record spans trail by about a day                  |
| Preliminary values                                       | Fetched again each month for the last three years, for sources that check their values later |
| Station lists, datum links and measured offsets          | Refreshed each month                                                                         |
| History                                                  | Backfills are still running for several sources, so some stations have no values yet         |
