`sources.json` has one object per source in the store: the agency or dataset that publishes its stations' values, with the terms they come under and where to report an error. It's rebuilt with [`stations.parquet`](/docs/reference/stations/) each night and after each monthly refresh. It's a JSON array, which DuckDB reads with `read_json`.

## Schema

<Schema
  file="sources.json"
  columns={{
    id: "The source's ID, the `source` in `stations.parquet` and the first part of each station's `id`.",
    name: "The source's name.",
    url: "The source's home page for the data.",
    license:
      "The source's license, a struct with `id` (an SPDX identifier or the source's own name for its terms), `name`, `url`, `commercial_use` (whether the terms allow commercial use) and `redistribution` (whether they let anyone republish the data). These are the source's defaults; a station's own `license` and `commercial_use` can differ where a contributor's terms apply.",
    attribution: "The credit the source's data requires.",
    contact:
      "Where to report an error in the source's data, a struct with `email` and `url`. At least one is set.",
    terms:
      "What a user of the data should know about the terms, and the changes the store makes to the source's values.",
    finalizes:
      "Whether values the source first publishes as preliminary become final later. Where it's false, the source's preliminary values stay preliminary. See [Quality flags](/docs/guides/quality-flags/).",
    stations: "How many active stations the source has in `stations.parquet`.",
  }}
/>

## Examples

Each source with its license:

<QueryResult
  sql={`SELECT id, license.id AS license, license.commercial_use AS commercial_use, finalizes, stations
FROM read_json('https://stillwell.openwaters.io/sources.json')
ORDER BY id`}
/>

Sources whose terms bar commercial use, with what they say:

<QueryResult
  sql={`SELECT id, license.name AS license, terms
FROM read_json('https://stillwell.openwaters.io/sources.json')
WHERE NOT license.commercial_use
ORDER BY id`}
/>

Each source's stations in `stations.parquet`, active and in all, and how many differ from the source's commercial terms:

<QueryResult
  sql={`SELECT j.id, j.stations AS active, count(s.id) AS all_stations,
  count(*) FILTER (s.commercial_use <> j.license.commercial_use) AS own_terms
FROM read_json('https://stillwell.openwaters.io/sources.json') j
JOIN 'https://stillwell.openwaters.io/stations.parquet' s ON s.source = j.id
GROUP BY ALL ORDER BY j.id`}
/>

See the [Terms guide](/docs/guides/terms/) for what `license`, `commercial_use` and `attribution` require.
