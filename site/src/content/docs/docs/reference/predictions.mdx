Predictions are the source's own tide predictions, one Parquet file per station per UTC year: the predicted curve under `predictions/` and the predicted extremes under `predicted-extremes/`. Which a station has is in its `products` in [`stations.parquet`](/docs/reference/stations/). A path is the product, the station's `id` and the year, as in `predictions/rws/hoekvanholland/2026.parquet`; see [File paths](/docs/getting-started/#file-paths).

## Predicted curve

`predictions/<source>/<station>/<year>.parquet`:

<Schema
  file="predictions/rws/hoekvanholland/2026.parquet"
  columns={{
    time: "UTC, as `TIMESTAMPTZ`.",
    level_m: "The predicted level in meters, in `datum`.",
    flag: "Quality, on the same scale as observed levels. See [Quality flags](/docs/guides/quality-flags/).",
    source_flag:
      "The source's own flag, where it gives one; null otherwise. Older prediction files predate the column, so read several with `union_by_name = true`.",
    received: "When ingest first saw the value arrive; null where ingest didn't record it.",
    datum: "The reference `level_m` is measured from, the same on every row.",
  }}
/>

The surge, as observed minus RWS's own prediction, at its largest:

<QueryResult
  sql={`SET TimeZone = 'UTC';
SELECT o.time, o.level_m AS observed_m, p.level_m AS predicted_m,
  round(o.level_m - p.level_m, 2) AS surge_m
FROM 'https://stillwell.openwaters.io/obs/rws/hoekvanholland/2024.parquet' o
JOIN 'https://stillwell.openwaters.io/predictions/rws/hoekvanholland/2024.parquet' p USING (time)
ORDER BY abs(o.level_m - p.level_m) DESC LIMIT 3`}
/>

The join holds only where both files share a `datum`. Otherwise refer them to one datum first; see [Datums](/docs/guides/datums/).

## Predicted extremes

`predicted-extremes/<source>/<station>/<year>.parquet` has `time`, `level_m`, `type`, `flag` and `datum`. BSH's files also carry its lunar transit number and event index:

<Schema
  file="predicted-extremes/bsh/506P/2026.parquet"
  columns={{
    time: "UTC time of the predicted high or low water.",
    level_m: "The predicted level in meters, in `datum`.",
    type: "`high` or `low`.",
    flag: "Quality, on the same scale as observed levels. See [Quality flags](/docs/guides/quality-flags/).",
    transit: "BSH only: its number for the lunar transit the high or low water follows.",
    event:
      "BSH only: which one it is after that transit: 1 high water after the upper transit, 2 low water after the upper, 3 high water after the lower, 4 low water after the lower.",
    datum: "The reference `level_m` is measured from, the same on every row.",
  }}
/>

The next predicted extremes at Cuxhaven:

<QueryResult
  sql={`SET TimeZone = 'UTC';
SELECT time, type, level_m, transit, event, datum
FROM 'https://stillwell.openwaters.io/predicted-extremes/bsh/506P/2026.parquet'
WHERE time >= TIMESTAMPTZ '2026-11-01'
ORDER BY time LIMIT 4`}
/>

The year's highest predicted high waters at Hoek van Holland:

<QueryResult
  sql={`SET TimeZone = 'UTC';
SELECT time, level_m, datum
FROM 'https://stillwell.openwaters.io/predicted-extremes/rws/hoekvanholland/2026.parquet'
WHERE type = 'high' ORDER BY level_m DESC LIMIT 3`}
/>
