The [duckdb](https://r.duckdb.org/) package runs the same SQL as the [DuckDB CLI](/docs/examples/tools/duckdb/) and returns data frames. It reads the store's files over HTTPS, fetching only the parts a query needs.

Every example uses Hoek van Holland, `rws/hoekvanholland`.

## Install

```r
install.packages(c("duckdb", "DBI"))
```

```r
library(DBI)

store <- "https://stillwell.openwaters.io"
con <- dbConnect(duckdb::duckdb())
dbExecute(con, "SET TimeZone = 'UTC'")
```

DuckDB downloads its `httpfs` extension the first time it reads an `https://` path.

## Read the station list

[`stations.parquet`](/docs/reference/stations/) has one row per station. The active ones with observed levels:

```r
stations <- dbGetQuery(con, sprintf("
  SELECT id, name, lat, lon, datum
  FROM '%s/stations.parquet'
  WHERE status = 'active' AND list_contains(products, 'levels')
", store))
```

## Find a station

```r
dbGetQuery(con, sprintf("
  SELECT id, name, datum, datums['LAT'] AS lat_offset_m
  FROM '%s/stations.parquet'
  WHERE name ILIKE '%%hoek van holland%%' AND source = 'rws'
", store))
```

`%%` is a literal `%` in `sprintf`.

## Read a year of levels

Each station's observed levels are one file per year at `obs/<source>/<source_id>/<year>.parquet`. `flag <= 2` leaves out values flagged as suspect or bad:

```r
levels <- dbGetQuery(con, sprintf("
  SELECT time, level_m
  FROM '%s/obs/rws/hoekvanholland/2024.parquet'
  WHERE flag <= 2
  ORDER BY time
", store))
```

## Read several years

HTTPS has no directory listing, so a wildcard path doesn't work, and a missing file is an error. Build the list of files from [`stations/years/<source>.parquet`](/docs/reference/series/#which-years-a-station-has), which has a row for every year file that exists:

```r
years <- dbGetQuery(con, sprintf("
  SELECT year FROM '%s/stations/years/rws.parquet'
  WHERE id = 'rws/hoekvanholland' AND epoch = 1 AND year BETWEEN 2020 AND 2024
  ORDER BY year
", store))$year
files <- sprintf("'%s/obs/rws/hoekvanholland/%d.parquet'", store, years)

levels <- dbGetQuery(con, sprintf("
  SELECT time, level_m
  FROM read_parquet([%s], union_by_name = true)
  WHERE flag <= 2
  ORDER BY time
", paste(files, collapse = ", ")))
```

`union_by_name = true` lets files with different columns read together, since some older files lack `source_flag`. `epoch = 1` keeps to the station's plain path; a station whose source moved it to another reference has later files under `obs/<source>/<source_id>/<epoch>/`, as [Datum epochs](/docs/reference/datums/#datum-epochs) describes.

The path holds the station's `source_id` URL-encoded twice, so an `@` is `%2540`. Only one station in the store has a character that needs it. [File paths](/docs/getting-started/#file-paths) has the rule, and DuckDB's `url_encode(url_encode(source_id))` builds it.

## Convert to another datum

`datums` maps each datum the station has an offset to, in meters, to add to a level in its own `datum`. Hoek van Holland's levels are in NAP; adding `datums['LAT']` refers them to LAT:

```r
levels <- dbGetQuery(con, sprintf("
  SELECT o.time, round(o.level_m + s.datums['LAT'], 3) AS level_m
  FROM '%1$s/obs/rws/hoekvanholland/2024.parquet' o,
    (SELECT datums FROM '%1$s/stations.parquet' WHERE id = 'rws/hoekvanholland') s
  WHERE o.flag <= 2
  ORDER BY o.time
", store))
```

`datums` describes the station's current epoch. [Converting a level](/docs/reference/datums/#converting-a-level) covers earlier epochs, and [Credits](/docs/reference/datums/#credits) the credits owed for offsets that don't come from the source.

## Things to know

- Times are UTC. DuckDB returns them as `POSIXct`; run `SET TimeZone = 'UTC'` so SQL that works with dates and hours, such as `date_trunc`, works in UTC too.
- Levels are meters, in the `datum` column of the same file.
- `level_m` is a 32-bit float. Round the result of adding an offset to 3 places.
- Select only the columns you need. DuckDB then reads only those columns' bytes from each file.
- Close the connection with `dbDisconnect(con, shutdown = TRUE)` when you're done.
- [Series](/docs/reference/series/) describes every column and product, including extremes and predictions.
